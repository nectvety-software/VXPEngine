# RetroBeachFighterDemo

240x320 MRE sample derived from the supplied retro beach fighting-game video.

Features:
- Stage2D horizontal camera with dead-zone;
- sky, cliff, water and ground parallax bands;
- scanline raster-wave ocean;
- RGB565 palette/tint cycling;
- procedural A8 fighter sprites;
- splash particle bursts and simple HUD;
- 30 FPS update.

Controls:
- 4/Left, 6/Right: move player/camera.
- 2/Up: jump.
- 5/OK: attack + splash.
- RSK/Back: exit.
