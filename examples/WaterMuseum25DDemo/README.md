# WaterMuseum25DDemo

240x320 MRE sample demonstrating the VxpScene25D pipeline inspired by the
visual composition of the supplied Water Museum fishing video.

Features:
- perspective textured pool/water plane;
- depth-scaled RGB565+A8 billboards;
- projected ellipse shadows;
- world-space fishing rope;
- green fog and colour grade;
- low-resolution additive lightmap;
- fixed particle splash;
- 30 FPS timer.

Controls:
- Left/Right: move fishing target.
- Up/Down: move target in depth.
- 5/OK: splash burst.
- Back/RSK: exit.
