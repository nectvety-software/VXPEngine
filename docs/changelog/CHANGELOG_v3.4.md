# VXPEngine v3.4.0

- Tất cả mẫu TitleSet và node trong Frame Preview có 8 tay nắm kéo dãn trực tiếp.
- Kéo cạnh để đổi riêng chiều rộng hoặc chiều cao; kéo góc để đổi cả hai.
- Giữ Shift để khóa tỉ lệ; có tùy chọn khóa tỉ lệ lâu dài trong menu Biến đổi.
- Hỗ trợ kéo dãn một thành phần, nhiều thành phần hoặc cả nhóm.
- Scene `.dtfe` và `VXPEngineSceneBindings.java` tự cập nhật Scale X/Y, display width/height, resizable và lock-aspect.
- Chuột phải → Biến đổi → Đặt lại kích thước 100%.
