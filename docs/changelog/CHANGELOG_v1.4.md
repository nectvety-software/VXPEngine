# Nova2D Engine v1.4

## Added

- Trang tài liệu offline tích hợp bằng PySide6 `QTextBrowser`.
- 22 chủ đề tài liệu có tìm kiếm toàn văn và điều hướng trước/sau.
- Nút Tài liệu tại Home.
- `F1` và menu Help mở tài liệu Nova2D.
- Nút About trên title bar mở chủ đề thông tin phiên bản.
- Liên kết chính thức đến libGDX Wiki.
- Tài liệu độc lập HTML và Markdown trong thư mục `docs`.
- QSS riêng cho toàn bộ giao diện tài liệu.

## Changed

- `ENGINE_VERSION` nâng lên `1.4.0`.
- Engine card tại Home đọc phiên bản động từ `project_store.py`.
- Windows AppUserModelID đổi thành `Nova2D.Engine.1.4`.

## Documentation coverage

- Cài đặt, project management, editor UI và project structure.
- Java/libGDX lifecycle, assets, input, camera, audio và physics.
- JNI/CMake/C++ native.
- Desktop/Android build, console, troubleshooting, shortcut, FAQ và roadmap.
