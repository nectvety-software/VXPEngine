# VXPEngine v3.9.0

## Editor Assets
- Các nút công cụ ở toolbar và khu vực vẽ chuyển sang dạng **icon-only**.
- Khi rê chuột lên icon sẽ hiện **tooltip/toast title** kèm mô tả và phím tắt.
- Thêm nhiều **phím tắt** cho thao tác nhanh:
  - Ctrl+N: Tạo canvas trống
  - Ctrl+O: Nhập ảnh
  - Ctrl+Shift+I: Ghép ảnh
  - Ctrl+S: Lưu & áp dụng
  - Ctrl+Z / Ctrl+Y: Undo / Redo
  - V/B/E/F/I/C/H: đổi tool
  - Alt+1 / Alt+2 / Alt+3: đổi chế độ pixel 8/16/32-bit
  - G: bật/tắt lưới
  - Alt+A: mở Animation Player
  - F1: hiện gợi ý phím tắt ở thanh trạng thái
